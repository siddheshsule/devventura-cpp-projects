# Hopwire link shortener (C++)

Starter code for the Devventura project "Link shortener for Hopwire". How to build and run the
tests: [BUILDING.md](BUILDING.md).

| Path           | What it is                                         |
| -------------- | -------------------------------------------------- |
| `include/hop/` | Public headers: the functions you implement        |
| `src/`         | Your implementation. Look for `TODO(milestone N)`  |
| `app/`         | The `hop` console program (milestone 3)            |
| `tests/`       | Provided tests, one file per milestone (m1–m3)     |

The console from milestone 3: `./build/hop` (Windows: `.\build\Debug\hop.exe`).
