# Frostline sensor readings (C++)

Starter code for the Devventura project "Sensor readings summary for Frostline". How to build and
run the tests: [BUILDING.md](BUILDING.md).

| Path             | What it is                                        |
| ---------------- | ------------------------------------------------- |
| `include/frost/` | `Reading`, `Summary` and the functions you write  |
| `src/`           | Your implementation. Look for `TODO(milestone N)` |
| `tests/`         | Provided tests: `m1_parse_test`, `m2_summary_test` |
